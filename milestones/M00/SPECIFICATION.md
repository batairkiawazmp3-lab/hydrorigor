# M00 Specification — Baseline & Governance

## Objective

Create the rules and artifacts that keep HydroRigor's multi-agent build controlled, testable, and auditable.

## In scope

- governance documentation
- agent role definitions
- handoff protocol
- Git rules
- quality gates
- security/content integrity rules
- governance-only CI
- M01 specification
- M01 authorization prompt

## Out of scope

- framework scaffold
- npm dependencies
- production UI
- content import
- calculators
- affiliate links
- analytics
- deployment
- domain registration

## Acceptance criteria

- governance artifacts exist
- role boundaries are explicit
- no external mutation is authorized
- M01 scope is precise
- CI governance check is syntactically plausible and contains no secret
- current handoff points to M01 authorization
