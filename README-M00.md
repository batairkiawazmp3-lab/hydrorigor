# HydroRigor M00 — Baseline & Governance

Status: **READY FOR M01 AUTHORIZATION**

M00 is intentionally non-build. It defines how HydroRigor will be built, reviewed, tested, handed off, committed, and promoted through milestones.

## Locked product baseline

- Brand: HydroRigor
- Positioning: Evidence-based hydroponics for home growers.
- Architecture: Astro 7.3.x, Node.js 24 LTS, TypeScript strict, Tailwind CSS 4.3
- Content: Astro Content Collections + MDX
- Hosting: Vercel
- Launch model: static-first; no database or external CMS at launch
- Production launch target: after M06/M07 quality gates with 25 real articles + 2 tools

## M00 rule

No production website code is authorized during M00.

Allowed:
- governance files
- milestone specifications
- CI governance workflow
- prompts/handoff templates
- documentation

Not allowed:
- Astro scaffold
- package installation
- UI components
- production deployment
- domain purchase
- affiliate account changes

The build begins only when M01 is explicitly authorized.
